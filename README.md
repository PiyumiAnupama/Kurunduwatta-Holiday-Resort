  <h2 id="overview" style="color: #34495e;">🌟 Overview</h2>
  <p>
    The <strong>Kurunduwatta Holiday Resort</strong> website is a static web application designed to promote a holiday resort located in Galle, Sri Lanka. It provides visitors with information about the resort's accommodations, services, booking process, and contact details. The website highlights the resort's unique offerings, such as Ayurveda treatments, and a tea plantation tour, catering to travelers seeking a relaxing and cultural experience.
  </p>
  <p><strong>Key Benefits:</strong></p>
  <ul>
    <li><strong>Ease of Use</strong>: Simple navigation with links to Home, Services, Booking, and Contact pages.</li>
    <li><strong>Informative</strong>: Detailed information about accommodations, policies, and services.</li>
    <li><strong>Visually Appealing</strong>: Uses images and a consistent design to showcase the resort.</li>
  </ul>

  <h2 id="features" style="color: #34495e;">✨ Features</h2>
  <ul>
    <li><strong>Home Page</strong>: Displays a gallery, resort description, and nearby attractions like Galle International Cricket Stadium and Dutch Church Galle.</li>
    <li><strong>Services Page</strong>: Lists room types (Three-Bedroom, Deluxe Double Room with Balcony), hotel policies, food & drink facilities, and customized tour packages.</li>
    <li><strong>Booking Page</strong>: Provides a form to collect guest details (name, email, telephone, check-in/out dates, group size).</li>
    <li><strong>Contact Page</strong>: Includes a map image and a message encouraging inquiries about personalized experiences.</li>
    <li><strong>Navigation</strong>: Consistent menu across all pages for easy access to Home, Services, Booking, and Contact.</li>
  </ul>
